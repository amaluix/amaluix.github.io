I help connect customer conversations with the systems and people that can resolve them. WhatsApp is one place that work can begin.

Plan the boundaries

The assistant should have a specific job and a clear limit. Sensitive actions and unexpected requests need an explicit path for review.

  • Identify what the assistant can answer from approved information.
  • Map which actions need access to an existing business system.
  • Define how a conversation reaches the right person.
  • Test missing information, failed integrations, and requests outside scope.

Before we talk

Can it use existing systems?

That depends on the system’s API, permissions, and the workflow. The Shifa implementation illustrates connections between WhatsApp, Nuacare, and Chatwoot; it does not establish compatibility with every product.

Can it include voice notes?

AI voice-note replies are part of the reviewed Shifa implementation. The portfolio includes a synthetic welcome preview. Languages, delivery requirements, and quality for your own use case need to be confirmed.

Will people still be involved?

Human handoffs are part of the approach. We should define the issues an assistant can handle, the cases a person should review, and the team responsible for follow-up.
